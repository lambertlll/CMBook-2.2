# financial-report-analyzer 操作指南（Agent 执行用）

> 本文件是 financial-report-analyzer skill 的执行入口说明。完整正式指令见 SKILL.md；
> 如需完整版可用 `skill_load`（file_type 传 `SKILL.md`）加载。

## 输入

调用方会给出：客户名称、客户类型、所属行业（可空）、客户文件夹路径、**确切输出路径**。
若缺少输出路径，先向用户确认，不要自行编造。

## 报告版本

触发后主动询问「简化版还是详细版」：简化版基于内部信息+财经媒体数据快速成稿；详细版深度解读年报原文，适合正式汇报。调用方已明确版本或用户要求直接生成时跳过询问，无法确认时默认简化版并说明可重生成详细版。

## 执行流程（严格按顺序）

1. **确认客户与版本**：客户名、行业、版本、输出路径齐全才开始。
2. **本地知识库融合（不要跳过）**：用 `search_markdown_files`（mode=`rag`，folderPath=客户文件夹路径，query 依次用「客户名 经营」「客户名 产能」「客户名 订单」「客户名 资金安排」「客户名 授信」）检索历史拜访纪要、尽调报告与资料；必要时用 `list_markdown_files` / `read_markdown_file` 精读。整理「内部已知经营信息」：客户自述的产能、订单、资金安排、经营计划、承诺口径，逐条注明出处文件名。内部口径与公开数据有出入时并列呈现并提示核实。
3. **公开信息获取**：简化版用 `web_search` 搜财经媒体核心财务数据（按当前日期确定最新财报期）与近 3 个月动态；详细版优先抓取年报原文页面（巨潮/披露易/交易所/官网 IR），`web_fetch` 无法解析 PDF 时说明局限并降级为简化版+加深搜索补充。`web_search` 提示未配置时，跳过联网部分并说明。
4. **按模板成稿**：用 `skill_load` 加载模板（简化版 `references/financial-report-template.md`；详细版 `references/financial-report-detailed-template.md`），沿用十章结构。详细版每项指标必须说明构成与变动原因，不能只列数字。
5. **信息标注（硬性要求）**：本地知识库内容逐条标注 `【内部信息】` 并注明出处文件名；联网内容逐条标注 `【公开信息】` 并注明来源与日期。查不到写「未查询到公开信息」，禁止编造；异常指标用 ⚠️ 标注。
6. **写入并汇报**：用 `create_file`（已存在用 `update_markdown_file` 覆盖）把报告写入调用方给的**确切输出路径**，然后在回复中汇报 5-10 条关键结论摘要并注明报告路径。

## 合规

仅使用公开渠道信息与本应用本地知识库；报告仅供内部参考，不构成正式授信意见，授信建议以行内制度为准；风险信息如实呈现并提示需核实，不下定性结论。
