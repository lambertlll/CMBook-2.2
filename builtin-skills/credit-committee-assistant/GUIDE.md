# credit-committee-assistant 操作指南（Agent 执行用）

> 本文件是 credit-committee-assistant skill 的执行入口说明。完整正式指令见 SKILL.md；
> 如需完整版可用 `skill_load`（file_type 传 `SKILL.md`）加载。

## 输入

调用方会给出：客户名称、客户类型、所属行业（可空）、客户文件夹路径、**确切输出路径**。
若缺少输出路径，先向用户确认，不要自行编造。

## 执行流程（严格按顺序）

1. **确认客户与输出路径**：客户名、行业、输出路径齐全才开始。
2. **本地知识库融合（本行掌握情况，不要跳过）**：用 `search_markdown_files`（mode=`rag`，folderPath=客户文件夹路径，query 依次用「客户名 承诺」「客户名 授信」「客户名 待办」「客户名 拜访」「客户名 需求」）检索历史拜访纪要、尽调报告与资料；必要时用 `list_markdown_files` / `read_markdown_file` 精读。整理「本行掌握情况」：客户承诺口径及进展、授信线索、待办进展、既往报告已核实结论，逐条注明出处文件名。
3. **联网获取最新信息**：先确定当前日期再定最新财报期（不要搜过时数据），用 `web_search` 检索最新财报/业绩会解读、战略调整、行业政策与景气度、风险舆情（近 3 个月重点），重点页面用 `web_fetch` 精读。`web_search` 提示未配置时，跳过联网部分并说明。
4. **按模板成稿**：用 `skill_load` 加载 `references/credit-committee-report.md`，沿用九章结构：本行掌握情况 → 最新变化速览⭐ → 提问预测⭐ → 财务深度 → 行业深度 → 战略分析 → 行业特点 → 风险 → 待核实+会前清单。
5. **提问预测（核心价值）**：按最新变化类/战略调整类/行业环境类/常规财务类/拜访细节类生成；每个提问含数据支撑、可能原因、建议回答要点、需准备的补充材料。拜访细节类结合内部信息预测评委追问（承诺落实、口径一致性、授信条件变化）并准备应答口径；内外信息有出入时单独列为提问并提示核实。
6. **信息标注（硬性要求）**：本地知识库内容逐条标注 `【内部信息】` 并注明出处文件名；联网内容逐条标注 `【公开信息】` 并注明来源与日期。查不到写「未查询到公开信息」，禁止编造；异常指标用 ⚠️ 标注。
7. **写入并汇报**：用 `create_file`（已存在用 `update_markdown_file` 覆盖）把材料写入调用方给的**确切输出路径**，然后在回复中汇报关键结论摘要（最重要的最新变化、最高概率被问的 3-5 个问题、会前必补材料）并注明材料路径。

## 合规

仅使用公开渠道信息与本应用本地知识库；材料仅供内部使用；实际授信决策以行内制度和审批结果为准；风险信息如实呈现并提示需核实，不下定性结论。
