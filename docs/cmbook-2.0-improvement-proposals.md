# 方案A：UI 重设计

## A1. 设计风格定位

**现代简约商务风**：以蓝色为信任主色（银行业属性），大面积留白 + 卡片化信息分组 + 克制的阴影层级。参考基调：Linear 的密度控制 + Notion 的内容留白 + 招行 App 的品牌蓝。

## A2. 设计规范（Design Tokens）

现有基础见 `src/app/globals.css`（L122-143），方案是在其上收敛，而非推翻。

| 令牌 | 值 | 说明 |
|---|---|---|
| **主色** `--primary` | `hsl(215 85% 42%)`（保留现值） | 招行蓝系，暗色模式 `hsl(213 90% 60%)` |
| 主色浅底 `--primary/8~12%` | 透明度派生 | 选中态背景、Hover 底色，禁止再引入新蓝色 |
| **辅助色-成功** | `hsl(152 60% 40%)` | 任务完成、导出成功 |
| **辅助色-警告** | `hsl(38 92% 50%)` | 任务进行中、待确认待办 |
| **辅助色-危险** | `hsl(0 72% 51%)` | 失败、删除、录音中红点 |
| **中性色** | 仅用 `foreground / muted-foreground / muted / border` 四档 | 清除现存 207 处硬编码灰 |
| **圆角** | `--radius: 0.5rem` 三档体系：sm=4px（输入框/标签）、md=6px（按钮）、lg=8px（卡片）、xl=12px（浮层/对话框） | 现有体系保留，补 xl |
| **间距体系** | 4px 基准网格：组件内 4/8、组件间 12/16、区块间 24、页面边距 16（窄栏）/24（内容区） | 统一 customer/meeting 模块目前混用的 p-3/p-4/p-5 |
| **字体层级** | 页面题 18px/semibold → 卡片题 14px/semibold → 正文 14px/normal → 辅助 12px/muted → 角标 10px | 字体族保留现有 `--notegen-app-font-family` |
| **阴影规则** | 平面元素无阴影只用 border；卡片 `shadow-sm`；浮层（菜单/弹窗）`shadow-md`；仅拖拽悬浮态用 `shadow-lg`。禁止彩色阴影 | |

# 方案B：结构与流程优化

> 仅针对体检报告中标注 🔴 / 🟡 的问题。

## B1. 纯内部重构（用户无感知）

| # | 对应 | 改什么 | 为什么 | 影响文件 | 行为变化风险 |
|---|---|---|---|---|---|
| B1-1 | 🟡S2 | 抽 `TranscribeEngine` 接口 + 公共基类（分段、重试、进度回调），SenseVoice/Qwen3/Aliyun 各实现差异部分 | 三份转写文件重复率高，改一处漏两处 | `meeting-transcribe.ts`、`meeting-transcribe-qwen3.ts`、`meeting-transcribe-aliyun.ts`，新增 `meeting-transcribe-base.ts` | **低**。纯抽取，输入输出不变；需回归三种引擎各转一次 |
| B1-2 | 🟡S4 | 拆分 article "上帝 Store"为 `article`（内容/保存）、`file-tree`（目录树/拖拽/排序）、`workspace`（工作区/锁定）三个 store | 8 类职责耦合，任何改动都有全量重渲染风险 | `src/stores/article.ts` 及约 30+ 个消费组件的 import 路径 | **中**。改动面广，靠 TypeScript 编译兜底；建议分两批迁移 |
| B1-3 | 🟡S5 | 消除 lib→app 反向依赖：把被 lib 引用的类型/函数下沉到 `src/lib/` 或 `src/types/` | 破坏分层，阻碍单测与复用 | `src/lib/` 中反向 import 的文件 + 对应 `src/app/core/` 源文件 | **低**。纯移动 + 改 import |
| B1-4 | 🟡S3 | 同步 Provider 抽 `BaseSyncProvider`（鉴权、冲突、重试骨架） | GitHub/Gitee/Gitea/GitLab 四份相似实现 | `src/lib/sync/` 各 provider + 设置页各 `*-sync.tsx` | **中**。同步涉及远端状态，需每个平台实测一轮 |
| B1-5 | 🟡S1 | 锁定依赖版本（去 `^` 浮动）、对齐 types 包版本、删未用依赖 | 构建可复现性 | `package.json`、lockfile | **低**。锁到当前已装版本，行为不变 |
| B1-6 | 🟡U1 | 207 处硬编码颜色替换为主题令牌（与方案A共用） | 暗色模式显示异常、主题色自定义失效 | meeting/customer 模块为主 | **低**。纯样式，逐模块截图对比 |

## B2. 会影响功能的改动（用户可感知）

| # | 对应 | 改什么 | 为什么 | 影响文件 | 行为变化风险 |
