## 常见坑速查

| 现象 | 原因 | 处理 |
|---|---|---|
| Agent 回复"请配置搜索 API Key" | 联网搜索未启用或无 key | 设置 → 联网搜索 |
| 文件生成了但知识库搜不到 | embedding 未配置 | 设置 → AI → 默认模型 |
| 转写失败 | STT 未配置或 key 失效 | 设置 → 音频 |
| 导出 Word 提示无 pandoc | pandoc 未安装/不在 PATH | 安装 pandoc 或直接用 md |
| 报告内容无内部信息 | 知识库检索时机 | 属正常（首次无积累），生成 1–2 份材料后再试即出现 |
| 详细版财报未读年报原文 | web_fetch 不支持 PDF（已知限制） | skill 会说明并降级，属预期 |
