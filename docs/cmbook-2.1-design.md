## 四、待办结构化（战略 1）

**已决策**：新建 `visit_todos` 表，**不写进 marks**（避免自动建客户标签污染用户标签体系、会议待办与随手记混流）。

```sql
CREATE TABLE IF NOT EXISTS visit_todos (
  id TEXT PRIMARY KEY,
  customerId TEXT DEFAULT '',   -- 手动添加的个人待办可为空
  visitId TEXT DEFAULT '',
  meetingId TEXT DEFAULT '',    -- 手动添加为空
  content TEXT NOT NULL,        -- 跟进事项
  owner TEXT DEFAULT '',        -- 负责人
  dueDate INTEGER DEFAULT 0,    -- 时限时间戳（0=无/待定）
  done INTEGER DEFAULT 0,
  createdAt INTEGER NOT NULL,
  updatedAt INTEGER NOT NULL
);
CREATE INDEX idx_visit_todos_customer ON visit_todos(customerId);
CREATE INDEX idx_visit_todos_done_due ON visit_todos(done, dueDate);
```

- schema_meta 升级 cmbook2 → **v2**（首次用上版本迁移机制）
- **提取**：纪要生成成功（导出入口）→ 解析「客户拜访纪要」模板固定的待办表（`| 序号 | 跟进事项 | 负责人 | 完成时限 |`，格式自控、解析可靠）→ 批量写入；同会议重新生成 → 按 meetingId 整批替换；非拜访会议/格式不匹配静默跳过
- **职责分离**：UI 勾选完成只改表，**不回写报告**（报告是档案，待办是执行）
- 客户工作区**不再单独做**待办区块（统一收口到右栏面板）

## 五、A/B/C/D 优化清单（已确认范围）

### A 类：高频体验痛点
- **A1 任务中心**：生成任务的会话自动命名（"宁德时代·访前尽调 07-23"），可回溯；客户工作区顶部"进行中的任务"横条
- **A2 三阶段改步骤条**：访前→访中→访后纵向排列 + 1→2→3 序号串联，替代挤在中栏的三窄列
- **A3 生成前置预检**：点生成前本地检查（搜索 key/embedding/纪要模型），缺项弹"去配置"直达提示
- **A4 菜单发现性**：客户列表/拜访卡片 hover 显示 "⋯" 按钮（DropdownMenu），右键保留为快捷方式
- **A5 完成提醒**：生成完成 toast + 对应阶段区块"新"红点/高亮（配合修复批的后台化任务）

### B 类：学习成本与清晰度
- **B1 知识库去技术化**："已索引/未索引"→"已学习/待学习"，"重建索引"收纳进折叠管理区，覆盖率改"AI 已学习 x/y 份材料"
- **B2 档案卡增强**：最近拜访日期/拜访次数/待办数三统计；后期从尽调报告回填实控人/主营/风险标签
- **B3 状态语义色**：录音中红/处理中黄/已完成绿/失败红描边（复用 meeting-list 的 StatusBadge 色系）
- **B4 文件列表降噪**：行内只留"文件名+日期"，路径/大小收进悬浮提示
- **B5 拜访类型**：新建拜访加快捷选项（首次拜访/定期回访/贷后检查/营销走访），供时间线过滤与 skill 上下文

### C 类：视觉打磨（选定三项）
- **C1 字号**：客户模块正文基准 text-xs → text-sm，或引导 uiScale
- **C2 空态教练化**：阶段区块空态改为行动引导文案（"还没有访前材料，点击下方按钮让 AI 生成 →"）
- **C5 拖拽上传**：知识库资料区支持拖文件上传
- （备选未选：C3 品牌色、C4 时间线折叠）

### D 类：设置页优化
- **D1 设置搜索**：顶部搜索框，按关键词过滤定位设置项并跳转（治本）
- **D2 分组重排 + 高级折叠**：常用（通用/AI 模型/会议/音频）/ 内容（编辑器/记录/文件/模板）/ 智能扩展（联网搜索/知识库/Skills）/ 系统（同步/快捷键/关于）/ 高级 ▸（MCP/提示词/记忆/图床/OCR/开发者，默认折叠）——21 项视觉压缩到 ~13 项
- **D3 配置健康检查**：设置首页顶部横幅显示核心三件套状态（聊天模型/embedding/联网搜索 key），缺项一键直达（与 A3 联动）
- **D4 文案去技术化**：RAG→知识库检索、Embedding 模型→知识库学习模型（技术名留描述里）
